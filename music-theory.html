乐理

发表于 2023-08-27 更新于 2026-09-04

声音是由声源振动产生的，通过机械波传递。

基础乐理

频率

声音的频率就是机械波的频率，也是声源振动的频率。频率对音高的贡献最大。比如声源振动 \(440\) 次每秒，频率就是 \(440\mathrm{Hz}\)。“每秒” 这个单位 \(\mathrm{s^{-1}}\) 也记作赫兹 \(\mathrm{Hz}\)，是国际单位制 “秒” 的导出单位。

纯音：频率单一的正弦曲线，横轴为时间，纵轴为瞬时声压。

复音：由纯音叠加而成，各个源叫分音。其中频率最低的分音叫基音，决定复音的音高；其他分音叫泛音，决定复音的音色。

有效弦长：一根弦上正在振动的部分。整个有效弦长的振动产生基音，也叫一次谐波或第一分音。频率为 f。有效弦长的 1/2 振动产生第一泛音，也叫第二分音或二次谐波。频率为 2f。有效弦长的 1/3 振动产生第二泛音，也叫第三分音或三次谐波。频率为 3f。f,2f,3f,4f,.. 统称谐性分音。

响度

声强：声波携带的能量。单位面积通过的声波功率，W/m^2

瞬时声压：声音造成空气压强的变化程度，声音经过后的空气压强 - 无声时的压强（标准大气压）。Pa。空气被压缩时为正，变稀疏时为负。正弦波的瞬时声压 p (t) = p_0 sin (2πft)；正弦波有效声压 RMS 等于振幅除以根号二。

声压级 SPL：20lg (RMS/20μPa)，dB

响度：人对声音强度的主观感受。等响曲线上各个点的响度相同，横轴为频率，纵轴为声压级，图像为一系列大致呈两边高的的曲线，越上的曲线更响。意味着在同声压级的情况下，中频或许比高频和低频更响。

乐音与噪音

乐音可被还原为一系列正弦波的叠加，它的音高由基频（一次谐波的频率）决定。噪音无明显固定的音高。

白噪音在单位频率上的能量一样。在线性频率坐标上，白噪音是水平直线，粉噪音是左高右低的直线（把白噪音提升低频，红 + 白）。在对数频率坐标的 EQ 上，正弦波是一个尖山峰，越低频的看起来越宽；白噪音是左低右高的直线，粉噪音是水平直线。

钢琴琴键的声音频率

  1. 规定一个基准频率，比如 \(440\mathrm{Hz}\)，作为第一个音。

  2. 把第一个音的频率乘上 \(\sqrt[12]{2}\)，就得到第二个音。一直乘，乘了十二次之后，第十三个音的频率正好是第一个音频率的两倍。

    这十三个音把一个 \(1:2\) 的频率区间分成了十二个部分，每个音的频率都是对应部分的端点，相邻两音的频率比为 \(1:\sqrt[12]{2}\)。这就是十二平均律。

  3. 如果把第一个音（\(440\mathrm{Hz}\)）记作 A4，往前乘十二次，得到 \(880\mathrm{Hz}\) 的音，就记作 A5。同理，再乘十二次，得到 \(1760\mathrm{Hz}\) 就是 A6。

    还可以往后除，\(220\mathrm{Hz}\) 是 A3，\(110\mathrm{Hz}\) 是 A2。

    同理。\(27.5\mathrm{Hz}\) 是 A0，\(3520\mathrm{Hz}\) 是 A7。

    A7 再往前乘三次，得到频率为 \(3520 \times \sqrt[4]{2} \mathrm{Hz}\) 的音，记作 C8。

  4. 从 A0 到 C8，有 88 个音，频率构成首项为 \(27.5\)，公比为 \(\sqrt[12]{2}\) 的等比数列。这就是 88 键钢琴每个琴键的频率。

上面是规定 \(\mathrm{A4=440Hz}\) 时，还可以有其他规定。

变音记号和变化音级

\(\sharp\) 为升号（sharp），用于把一个音升高半音。比如 \(\mathrm{B \sharp 4 = C5}\)。B#4 = C5。\(\flat\) 为降号（flat），用于把一个音降低半音。比如 \(\mathrm{D \flat 4 = C \sharp 4}\)。Db4 = C#4。重升号 x 重降号 ♭♭

自然音级是所有白键，变化音级是字母加上变音记号。五个黑键必然是变化音级，为 FCGDA 的升，或 GDAEB 的降。但变化音级可能是黑键或白键，如 Cx=D。

音程

两个音之间的频率比，称为音程。频率比为 \(1:2\) 的两个音之间，音程称为一个纯八度（简称八度）。

两个相邻琴键的频率比，比如 C4 和 C#4 之间，频率比为 \(1:\sqrt[12]{2}\)，称为一个半音。也叫小二度。两个琴键相隔一个琴键的频率比，比如 C4 和 D4 之间，频率比为 \(1:\sqrt[6]{2}\)，称为两个半音。也叫一个全音或大二度。1 半音 = 100 音分。正常人可分辨出 25 音分的差别。

度是两个音跨过的字母数。如 C4-C4 是纯一度，C4-C5 是纯八度。x 度 + y 度 =(x+y-1) 度。C 到 D 是大二度，C 到 D♯是增二度，C 到 E♭是小三度。D♯和 E♭是同音高的异名音（等音）。

自然音程指自然大调或自然小调中各音级可构成的音程，包括纯音程，大音程，小音程和增四减五度。自然调式以外的音也可以构成自然音程，如和声小调一级和二级音之间是大二度。但是自然调式之内的音无法构成变化音程。变化音程是除增四减五度之外的增 / 减音程，或倍增倍减音程，如和声小调六七级音之间的增二度。

五度圈

五度圈即在钢琴上以 C 为起点依次向后取（上行）纯五度关系的音，最后又回到了 C，且这一圈里包含了十二个完整的音名。FCGDAEB (FCGDE)♯ 或 FCGDAEB (GDAEB)♭

五度圈里顺时针上行是纯五度关系，逆时针上行 / 顺时针下行是纯四度关系。

钢琴键盘上的音程（试验）

从块的形状来看：

小二度是两个相邻的琴键，包括一黑一白和两白两种，这里把前者称为刀，其中白键是刀把，黑键是刀身。后者称为牙。牙只有 EF 和 AC。小二度是 1+1。

大二度是两黑夹一白或两白夹一黑，这里把前者称为小停（形似暂停键），后者称为三角（角，或二梯）。小停只有 C♯D♯，F♯G♯和 G♯A♯。三角有 CD DE FG GA 和 AB。大二度是 2+1。还可能是两白并排，旁边一黑，称作旗子。

小三度有三种情况：三带一、双刀（剃刀）和黑碗。三带一的特点是底下三个白键，黑键偏中左或中右；双刀是两把刀同向并列；黑碗是两把刀刀把朝内，刀身朝外，两个黑键在碗沿，也像间隔更大的暂停键（大停），四个键呈上大下小正放碗状。三带一必定两白，剃刀必定一黑一白，黑碗必定两黑。三带一只有 DF（偏左）EG（偏右）和 AC（偏左）BD（偏右）。黑碗或大停只有 D♯F♯和 A♯C♯。三带一和黑碗都跨缝了，剃刀都没跨缝。或者说，小三度全是三带一和两对。

大三度有四种情况：实心三带二（三梯）、偏心三带二（双刀白）、分心三带二（黑碗白）和梳子（三梳）。实心三带二即三白夹两黑，有 CE FA 和 GB。偏心三带二（如 C♯F）是双刀刀背处再并排个白键。分心三带二（如 D♯G）是黑碗再并排个白键，或者也等于刀背并排三角。梳子只有 F♯A♯。或者说，大三度全是三带二。

纯四度（差 5 半音）有四种情况：缺心四带二、偏心四带二（梯白）、三排刀和偏心梳子。偏心梳子只有 C♯F♯ D♯G♯ G♯C♯ 和 A♯D♯。或者说，纯四度全是四带二和飞机。

起末为黑键，且中间只有一个黑键的键型，必然是梳子或偏心梳子。其中梳子是三带二型的大三度，偏心梳子是飞机型的纯四度。

三全音音程（四带三 / 五带二）：只有 FB/BF 是两白键，其他都是一黑一白。且只有 BF 是五带二，其他都是四白三黑。

纯五 5+3，4+4。偏心五梯（缺五梯）CG；缺心四梳 C♯G♯；偏心四梳 D♯A♯；纯五度全是缺五梯或两连炸（缺四梳）。

起末为黑键，且中间只有两个黑键的键型，必然是偏心四梳、缺心四梳（二者统称缺四梳）或双缺四梳。其中偏心四梳（C♯G♯ D♯A♯ F♯C♯）和缺心四梳（G♯D♯）是两连炸型的纯五度，双缺四梳（只有 A♯F♯）是五带四型的小六度。

小六 5+4（双缺四梳），6+3，大六 6+4（飞机带翅膀 / 缺六梯），5+5（缺五梳），小七 6+5（双缺五梳），7+4。

起末为黑键，且中间只有三个黑键的键型，必然是缺五梳或双缺五梳。其中缺五梳如 C♯A♯是 5+5 型的大六度，双缺五梳是 6+5 型的小七度。

大七 7+5。键的总数减一就是相隔的半音数。

音程的和声性与旋律性

两音纵向叠置称和声音程，横向展开称旋律音程。 欣德米特序列一：C-G-F-A-E-E♭-A♭-D-B♭-D♭-B-F♯。越靠后的音离 C 关系越远。

欣德米特序列二：纯一度 / 纯八度 > 纯五度 / 纯四度 > 大三度 / 小六度 > 小三度 / 大六度 > 大二度 / 小七度 > 小二度 / 大七度 >| 增四度 / 减五度

P1、P8 是极完全协和音程，P4、P5 是完全协和音程。M3、m3、M6、m6 是不完全协和音程。另外的是不协和音程。如减四度 d4 和大三度 M3 是等音程，但后者是不完全协和的，前者是不协和的。纯五度和减六度同理。它们音数相同，度数不同。

序列二是对音程协和性的排名，但有时过于协和也不意味着和声 “好听”。在序列二里，和声性总体下降，但在大三度处为高峰。旋律性总体上升，但在大二度处为高峰。特别地，增四减五度和声性和旋律性都很低，该音程是纯八度的一半，称极音关系。

单一声部的旋律运动

沿着调式音阶内音级的顺序，二度称级进，三度称小跳，四度及以上称大跳。相同音高重复出现称同音反复。同音反复、级进和小跳称平稳进行。

音程的叠加

  • 小某度 + 增一度（小二度） = 大某度

  • 大 / 纯某度 + 增一度（小二度） = 增某度。如纯五度（7）+1 = 增五度（8）

  • 减某度 + 增一度（小二度）= 小 / 纯某度。如减六度（7）+1 = 小六度（8）

  • 二度 + 二度 = 三度的情况包括但不限于：

    • 小二度（1）+ 小二度（1） = 减三度（大二度）(2)
    • 大二度（2）+ 小二度（1） = 小三度（3）
    • 大二度（2）+ 大二度（2） = 大三度（4）

  • 大二度 + 小三度 = 纯四度

  • 大二度 + 大三度 = 增四度（6）= 减五度

  • 三度 + 三度 = 五度的情况包括但不限于：

    • 小三度 + 小三度 = 减五度 = 三全音
    • 大三度 + 小三度 = 纯五度
    • 大三度 + 大三度 = 增五度

  • 五度 + 三度 = 七度的情况包括但不限于：

    • 纯五度 + 大三度 = 大七度（11）
    • 纯五度 + 小三度 = 小七度（10）
    • 增五度（8） + 大三度 = 增七度（12）
    • 减五度（6） + 小三度 = 减七度（9）

音的循环与网格图

参考叶小胖《图解和声》

把 12 个音级当做十二个小时，以 C 为 12 点顺时针上行所得的钟面上的各个刻度，即为半音阶循环。图为圆周，或正十二边形。钟面共有六条直径，为六对三全音。全音阶循环为两个正六边形。小三度循环为三个正方形，构成减七和弦。大三度循环为四个正三角形，构成增三和弦。纯四度和纯五度循环为十二芒星。

网格图是一系列正三角形的密铺，每个顶点处有一个音级。

  • -60 度方向：小三度上行。
  • 60 度方向：大三度上行。
  • 0 度方向：纯五度上行。跨两格是大九度上行。
  • -30 度方向（菱形对角线）：小七度上行 / 大二度下行
  • 30 度方向（菱形对角线）：大七度上行 / 小二度下行
  • 90 度方向：半音阶（小二度）上行

水平方向是完全协和音程，向右是纯五度，向左是纯四度。60 度方向是不完全协和音程（也是协和音程），向右上是大三度，向左下是小六度。120 度方向是不完全协和音程（也是协和音程），向右下是小三度，向左上是大六度。

以 0 度方向为对称轴，30 度方向是大七度上行，与之对称的是 - 30 度方向的小七度上行。60 度方向是大三度上行，-60 度方向是小三度上行。以纯四度方向为参照轴，向上转 30 度是大二度上行，向下转 30 度是小二度上行。

音名和唱名

音名（pitch name，音高名称）：C4、C#4、D4 等是音名，对应绝对音高。比如 \(\mathrm{C4 = 220 \times \sqrt[4]{2} Hz}\)。

唱名（sol-fa note，唱名表示法中的音符）：do、re、mi、fa、sol、la、ti 是圭多唱名法里的唱名，对应相对音高。在简谱里记作 1、2、3、4、5、6、7。我们可以规定 1 至 7 分别对应七个白键 C4 至 B4。这时简谱头部会有 \(\mathrm{1 = C}\)。在简谱里，如果用 \(1\) 表示 \(\mathrm{C4}\)，那么 \(\mathrm{\dot{1}}\) 就表示 \(\mathrm{C5}\)。\(\mathrm{\dot{\dot{1}}}\) 表示 \(\mathrm{C6}\)，\(\underset{·}{1}\) 表示 \(\mathrm{C3}\)，以此类推。

首调和固定调唱名法

固定调唱名法的 do 永远是 C，即 do 到 ti 固定在了 C 大调上。首调唱名法可以改变。

D 大调音阶 D E F♯ G A B C♯。首调唱作 do re mi fa sol la ti （do=D）。需要相对音感（线性音高经验）。用于分析和声，视唱简谱。固定调唱作 re mi fi sol la ti di （do=C）。需要绝对音感（点状音高经验）。用于视唱五线谱。

特别地，有种在固定调里给黑键赋予唱名的方法（柯达伊半音阶唱名）。其中升号音为 di ri fi si li，降号音为 ra me se le te。也有人认为每个黑键只用指定一个唱名。

C 小调音阶 C D Eb F G Ab Bb，用首调唱名（自然记法），可以用 la ti do re mi fa sol（la=C）。或者固定调（顺阶记法） do re me fa sol le te（do=C）。

无变音记号的情况下，高音谱第二线是 G，低音谱第四线是 F。高音谱下加一线和低音谱上加一线都是 C。高音谱第三线是 B，低音谱第三线是 D。高音谱上加一间是 G，低音谱上加一间是 B，由此可知低音谱第二线也是 B。低音谱第四间是 G，高音谱第四间是 E。因为高音谱第一线也是 E，所以低音谱第一线也是 G。A 在高音谱第二间、下加二线、上加一线，低音谱第一间、第五线。

低音谱第二间是 C3，高音谱第三间是 C5。低音谱第四线是 F3，高音谱第五线是 F5。

高音谱的四个间构成大七和弦 F△=FACE。FAC=F，ACE=Am。高音谱五线 EGBDF。EGB=Em，GBD=G，BDF=B°。EGBD=Em7 小七和弦（向左偏的菱形），GBDF=G7 属七和弦（斜边朝右上的直角三角形），属七可看作大三 + 减三。

低音谱四间构成小七和弦 Am7=ACEG。小七和弦可看作小三 + 大三。五线为 GBDFA。

高音谱某位置的音向上数两个字母得低音谱同位置的音。低音谱某位置向下数两个字母得高音谱同位置的音。若有一高一低的两谱表上下放，注意朝的是反方向。如高音谱第二间是 A，向上数两个是 C，则低音谱第二间是 C。低音谱相当于高音谱的框框整体向下移了一格（三度），若框框不动，就是音向上三度，低音谱同位置的音是高音谱音的向下十三度（八度 + 六度），向下六度就是向上三度，三度除了起点外就是数两个字母。

高音谱下加二线等于低音谱第五线（A3），低音谱上加二线等于高音谱第一线（E4）。

若符干起点视作在符头所在线 / 间的同位置，则符干长度画三格半，尾部在本音上方八度的同名音位置（二度为半格，三度为一格，四度为一格半，五度为两格）。如高音谱第一间的 F 音，符干起点在第一间，终点在第五线的 F。符头和符干尾一个在线上、一个在间上。

对于单个音符，若符头在第三线之下，则符尾向上；在第三线之上则符尾向下；在第三线上下均可。若符头在下加一间，则不用画下加一线，上加一间或许也如此。

四部和声用一对高低音谱表记，高音声部 S 在高音谱符干统一朝上，中音声部 A 在高音谱符干统一朝下，次中音声部 T 和低音声部 B 在低音谱上分别朝上和朝下。

若符头在间上，则附点画在同间的右边；符头在线上，附点画在上面间的右边。

四分休止符，从第四间向右下画到第三间，在中间两个间各拐弯两次，最后一次拐弯是一个向左上凸的弧，结尾在第一间。

八分休止符，符头在第三间，符尾在第二线。

一个符干两个符头一左一右，可能是二度的音程为节省空间而画的。

♯号的写法：G 大 / E 小调调号写在高音谱 F5，低音谱 F3。两个横向斜杠起点和终点撑满了 F 上下的两个间。

开头带升号的谱，升号所在位置对应的那条线或间上音符的绝对音高相对于无变音记号的谱高半音。

临时变音记号只在一小节内起作用，意味着在同一小节内若有两个升 C，升号只写在第一个 C 左边（线上或间上，意味着对本小节的这条线或间起作用），而默认了第二个没写的仍是升 C，除非在左边加了还原号。注意五线谱上临时变音记号是写在音符左边的。长期的变音记号写在谱号右边。

连线记号表示多个音符唱成一个音，有延音和滑音。

自由延长记号没有固定的延长要求。断奏记号（符头正上方或正下方圆点）时值缩短四分之一到二分之一。

两细竖线叫段落线，一细一粗叫终止线。一粗一细带冒号是反复，只有右边有是从头反复。

力度记号：pp 很弱 p 弱 mp 中弱 mf 中强 f 强 ff 很强，电子琴需有力度功能，由击键速度控制力度。双手力度相同时，力度记号写在两行谱表的中间。力度不同时，记在各自对应的谱表上方或下方。<> 渐强 渐弱。

速度记号：rit. 渐慢

legato：连音奏法，大概是保持音符之间没有间断，“已弹下的手指保持到另外的手指弹下去后才抬起”。

音阶

音阶（scale，尺度）是按基本频率或音高排序的任何一组音符。按音高递增排序的音阶是升序音阶，按音高递减排序的音阶是降序音阶。如 A0 B0 C1 D1 E1 F1 G1 A1 B1 ... C4 D4 E4 F4 G4 A4 B4 ... C7 D7 E7 F7 G7 A7 B7 C8 就是一组升序音阶，对应钢琴的所有白键。在上面的例子中，每个八度里用到了七个音名 C D E F G A B（不包括区间右端点），这被称为七声音阶。

或许要背的音阶：五度圈 FCGDAEB (FCGDA)♯ 或 FCGDAEB (GDAEB)♭。五个黑键 (CDFGA)♯或 (DEGAB)♭。自然音级三度循环 CEGBDFAC

音阶相同是什么意思：\(\mathrm{C-D-E-F-G-A-B}\) 和 \(\mathrm{A-B-C-D-E-F-G}\) 音阶相同吗？这两组音阶分别都是同一个八度里的音（不包括右端点）。如果把 “音阶” 理解为无限扩展到多个八度后，所有音的绝对音高的话，得到的答案是相同的，因为它们都使用了钢琴的所有白键。但这两组音阶是不同的。原因在于：首先，主音不同。前者以 \(\mathrm{C}\) 为主音，后者以 \(\mathrm{A}\) 为主音。其次，音级之间的音程关系（相隔的半音数）不同。前者为 \(2-2-1-2-2-2-1\)，后者为 \(2-1-2-2-1-2-2\)。（算上下一个八度里的主音）。我们说两组音阶相同，意思是它们的主音、音程关系都相同，或者说是讲顺序的。

调式音阶为主音 + 音程关系。如：C 大调音阶为：\(\mathrm{C-D-E-F-G-A-B}\)。A 小调音阶为：\(\mathrm{A-B-C-D-E-F-G}\)。它们使用的音名相同，叫关系大小调。

七声音阶的音级

七声音阶里有七个音级（degree，刻度）：主音 - 上主音 - 中音 - 下属音 - 属音 - 下中音 - 导音

各音级与主音的相对位置

  • 主音（一级，Tonic，使精神振奋的）是调性的核心，所有音最终都要返回它。
  • 属音（五级，Dominant，占优势的）在主音上方五度。
  • 下属音（四级，Subdominant）在主音下方五度，上方四度。
  • 中音（三级）在主音上方三度，在主音和属音中间。
  • 下中音（六级）在主音下方三度，上方六度。在主音和下属音中间。
  • 上主音（二级）在主音上方二度。
  • 导音 / 下主音（七级）在主音下方二度。

自然大调的七级叫导音。自然小调的七级叫下主音，对主音的趋向性比大调弱。因为大调导音 VII - 主音 I 是小二度，小调下主音 VII - 主音 I（如 A 小调 G-A）是大二度。对主音来说，调内音的半音趋向性比全音趋向强。

等音程循环音阶

大二度循环：三白键接三黑键，或两黑键接四白键。其中黑黑是停，白白是角，黑白 / 白黑是旗。

小三度循环：减七和弦，双黑键的有八个，三黑键的有四个。块自身完全对称的是 Cdim7 和 Gdim7。还有两两对称的，如 C#dim7 和 F#dim7 的形状关于 G# 音对称。

大三度循环：增三和弦，双黑键的有 9 个，单黑键的有三个。完全对称的是 Eaug 和 A#aug。

纯四度循环（四带二或飞机）：从 A# 出发，途径四个偏心梳子把五个黑键走完到 F#，之后是到 B 的飞机，之后 BEADGCF 全是四带二，之后是 F 到 A# 的飞机。从 A#0 到 F5 已走完一圈。

纯五度循环（53/44）：从 F1 一直走到 A#7。白白或黑白间是五三，黑黑间是 44。

调式

广义的调式 = 八度内的使用的音级数 + 音程关系。狭义的调式 = 八度内的使用的音级数 + 音程关系 + 主音。

  1. 确定一个起始音（主音）。
  2. 从主音开始，往后（高音方向）取不同的音级。这些不同的音相隔的半音数可能不同，直到取完一个八度。
  3. 再往前、往后取，直到取完所有八度。

比如以 C 为主音，音程关系为 2-2-1-2-2-2-1 的调式，称为 C 自然大调。 C Major 用到的音名为：...B3-C4-D4-E4-F4-G4-A4-B4-C5... 。以 A 为主音，音程关系为 2-2-1-2-2-2-1 的调式，称为 A 自然大调。A Major 用到的音名为：...G♯3-A3-B3-C♯4-D4-E4-F♯4-G♯4-A4...

以 A 为主音，音程关系为 2-1-2-2-1-2-2 的调式，称为 A 自然小调。A Minor 用到的音名为：...G3-A3-B3-C4-D4-E4-F4-G4-A4...

X 自然大调的 6 级是其关系（X+M6）小调的 1 级，Y 小调的 3 级是其关系（Y+m3）大调的 1 级。X 大调的主音上行大六度（9 半音）或下行小三度，即为 X 大调的关系 Y 小调，和 X 大调在五线谱上用同一个调号。

移调（transpose）就是把所有音同时升高或降低相同的半音数。移调前后，所有音的相对间隔不变。即音程关系不变。

调的本质是把各音区别对待，等级为主音 - 调内音 - 调外音。

升号调和降号调

自然大调有 7 个升号调和 7 个降号调。它们每个调的特点是每个字母只出现一次、每个音最多加一个变音记号、总的变音记号不超过七个。

  • G 大调：升 F。从钢琴上看，把 C 大调音阶那一坨的形状平移到从 G 开始，发现从六级音 E 之后的黑键和原来的位置差了一格，而六级到七级是需要大二度的，于是 F♯为调内音。
  • D 大调：升 F、C
  • A 大调：升 F、C、G
  • E 大调：升 F、C、G、D
  • B 大调：升 F、C、G、D、A
  • F# 大调：升 F、C、G、D、A、E
  • C# 大调：升 F、C、G、D、A、E、B （4152637）

主音向下数半音是最后一个升号音级，如 D 大调主音是 D，向下数半音是 C♯，于是 D 大调升 FC。F♯大调主音向下数半音是 F（E♯），于是 F♯大调升 FCGDAE。如果忽略 F# 和 C# 大调，即五线谱高音谱号右边最多写五个升号的话，则最后一个升号的下一个字母就是大调的主音。

  • F 大调：降 B
  • Bb 大调：降 B、E
  • Eb 大调：降 B、E、A
  • Ab 大调：降 B、E、A、D
  • Db 大调：降 B、E、A、D、G
  • Gb 大调：降 B、E、A、D、G、C
  • Cb 大调：降 B、E、A、D、G、C、F (7362514)

主音去掉降号是倒数第二个降号音级。如果忽略 Gb 和 Cb 大调，即高音谱号右边最多写五个降号的话，则倒数第二个降号音就是大调的主音，特别地，只降 B 的是 F 大调。

升 C 和降 C 大调基本不用，改写成降 D 大调和 B 大调。

为什么 D 大调不是降号调：每个字母只能出现一次。D 大调用降号写是 D, E, Gb, G, A, B, Db。类似地，C 小调是降号调。

调内和弦

以 C 大调上的三和弦为例，它是在 C 大调音阶上取三个三度关系的音级构成和弦。有七个音级，每个都可以作为根音，于是七个和弦分别为：C Dm Em F G Am B°。在一级、四级、五级上（以它们为根音）的和弦都是大三和弦，也叫主和弦、下属和弦、属和弦。它们叫大调上的正三和弦，另外四个叫大调上的副三和弦。

类似地，所有大调的七个三和弦都是【大 - 小 - 小 - 大 - 大 - 小 - 减】，因为：

  • 2-2-1-2-2-2-1
    • (2+2)+(1+2)=(4+3)= 大三和弦
    • (2+1)+(2+2)=(3+4)= 小三和弦
    • ……
    • (1+2)+(2+1)=(3+3)= 减三和弦
    • 以此类推

类似地，小调的各级三和弦为：【小 - 减 - 大 - 小 - 小 - 大 - 大】。这和小调相对于大调的音程关系看起来类似，都是把大调的 6 当成小调的 1。

  • 大调的各级七和弦为：【大 - 小 - 小 - 大 - 属 - 小 - 导】。
  • 小调的各级七和弦为：小 导（减小）大 小 小 大 属（大小）

调内和弦的级数记法：X 大三和弦，x 小三和弦，X△大七和弦，X7 属七和弦，x7 小七和弦（不记作 Xm7），xø 导七和弦。x△小大七和弦。x°7 减七和弦，x° 减三和弦，X + 增三和弦。

副调和弦

以本调调内和弦为主和弦的其他调，称为本调的副调。如 C 小调的三级和弦是 E♭，它在 E♭大调里做主和弦，于是 E♭大调为 C 小调的副调。使用副调上的和弦称离调。离调最后要回去的，不回去称转调。

副属和弦即副调上的属和弦。如 Eb 大调是 C 小调的副调，Eb 大调的属和弦是 Bb，则 Bb 是 C 小调的副属和弦。Bb 和弦在副调（Eb 大调）上的级数是 V，副调的主和弦（Eb）在主调（C 小调）上的级数是 III，于是 Bb 和弦在 C 小调下的级数是 V/III，意味着 “C 小调 III 级上的副属和弦”，即以 C 小调 III 级和弦为主和弦的其他调上的 V 级和弦。

Gm 在 C 小调下可记作 V/I，意为 C 小调一级上的副属和弦。

C 大调三级和弦为 Em，是 E 弗里吉亚调式的主和弦，E 弗里吉亚的属和弦是 Bdim。。。？这里的副调只是指在大小调范围内的？Em 是 E 小调的主和弦，E 小调的属和弦是 Bm，于是 C 大调三级上的副属和弦 V/iii 为 Bm？但是 Bm（BDF#）没有向临时主音 E 的导音，属功能不足，所以把 D 升半音，Bm 变为 B。

十二律

十二律由三分损益法得到十二个绝对音高黄钟、大吕... 仲吕。用到 3/2 和 3/4 的比例。

一根律管长度为 1，振动频率为 f。称黄钟。割掉三分之一（即乘上 2/3）后，剩 2/3，频率变为 3/2f。称林钟。把 2/3 的管长再加长它的三分之一（即乘上 4/3），变为 9/8f，称太簇。然而直到仲吕再损一后，得到的清黄钟与黄钟长度的一半有差距，称黄钟不能还原。

宫商角徵羽类似唱名 do re mi sol la。若黄钟 = C = 宫，则生律的顺序为宫徵商羽角，CGDAE。

五度相生律

频率比 2/1 称为纯八度，3/2 称为纯五度，4/3 称为纯四度。用弦长直接向上乘 3/2 五次或六次、向下乘 2/3 六次或五次，再把得到的长度乘或除以 2 的幂，把它们归到同一个八度里。

在十二平均律里的纯五度是 (12 次根号 2)^7，约等于 1.498。纯四度约等于 1.335。

弦外音

和弦托住的是旋律。旋律音若在与之同时发声的和弦里，称和弦音，否则称弦外音。这里的同时发声也包括分解和半分解和弦，在和弦整体发声的范围内，即使分解和弦的一部分与旋律音同时发声（如 CEG 分解，旋律音 E 只和 C 同时响了），判断旋律音是否为弦外音还要考虑到整个和弦的音。

弦外音的形式：延留音、经过音、辅助音、先现音。延留音出现在强拍或次强拍上，除了延留音外，其他所有弦外音都出现在弱拍上。

延留音使与之音高接近的和弦音延迟出现（斯氏和声学教程）。延留音是上个和弦的音延留下来，作为本和弦的外音（百度百科）。

经过音以级进的方式，作为不同和弦音的过渡。如 C 和弦，旋律 CDE 里 D 是经过音。

辅助音以级进的方式，作为和弦音同音反复的过渡。如 C 和弦，旋律 EFE 中 F 是辅助音。

先现音是后一和弦音在弱拍上的提前出现。

自然大调的和弦

三和弦：其中 I IV V 是大三和弦，称大调的正三和弦。ii iii vi 是小三和弦，vii° 是减三和弦，称大调的副三和弦。

在网格图上看，每个正三和弦的左右两个相邻的调内三和弦分别构成三个功能组。主和弦 I 的左右两个倒置三角形分别是 vi 和 iii，它们分别有两个相同音。因此 I vi iii 称主功能组。属和弦 V 的左边是 iii，右边是 vii°，称属功能组。下属和弦 IV 的左边是 ii，右边是 vi，称下属功能组。

三和弦的主功能组 T 最稳定，稳定性为 163。下属功能组 S 次之，为 642。属功能组 D 最紧张，为 357。同功能组的和弦可互相替换使用，即六三代一、三七代五、二六代四。

声部的连接

横向的独立旋律线称声部。

两声部间运动的相对关系称对位运动。若运动方向一致，称同向进行，音程也一致称平行进行（包括如一大一小的三度），但两声部都同音反复不算平行进行，所以平行进行是斜的。反向进行包括扩张和收缩。斜向进行为一声部同音反复，另一声部上行或下行。

对位法：使多条旋律线同时进行且彼此融合。是复调音乐的技法。复调：关注各个声部的横向运动，在运动中调整融合关系与协和程度。

音的趋向：

  • 大小调都是主音 I 最稳定，中音 III 和属音 V 次之。其他调内音就近趋向它们。
  • 调外音向就近调内音的趋向性最强。
  • 半音的趋向性比全音强。

以 C 大调为例，调外音向调内音的趋向性 > E 和 G 向 C 的趋向性。其它的借助钟面判断。可知大致为 431，651，71 和 21。
